# CombustionFe

R and Python scripts as utilized for the publication entitled: 
"Residential burning is a potentially significant source of soluble iron to the ocean",
under review in Atmospheric Chemistry and Physics - EGU. 

Supporting scripts to clean and visualize modeling output data 
are provided in this repository.

All data and programming scripts are labeled with 
Creative Commons Attribution 4.0 labeled for cited reuse.

Please see the zenodo repository specifically for use of the 
emissions inventories and model outputs for source-attributed aerosol-Fe: 
10.5281/zenodo.17903186
